# River Fractal Analysis

**River Fractal Analysis** — настольное приложение на Python для фрактального анализа речных сетей и водосборных бассейнов.

Программа предназначена для обработки табличных гидрологических и геоморфологических данных, полученных после предварительной подготовки в ГИС. Приложение позволяет загружать CSV-файлы, отображать данные в таблице, выполнять расчёты фрактальных характеристик речной сети и сохранять результаты в новый CSV-файл.

## Возможности

Приложение поддерживает несколько модулей анализа:

### 1. Соединение фрагментов водотоков

Модуль объединяет отдельные отрезки водотоков в связные компоненты по начальным и конечным узлам.

Используется для того, чтобы из фрагментированных речных сегментов получить целостные водотоки.

Результат работы модуля:

- присвоение ID объединённым водотокам;
- опциональный расчёт суммарной длины объединённого водотока;
- добавление новых колонок в исходную таблицу.

### 2. Расчёт фрактальной размерности границ бассейнов `D`

Модуль рассчитывает фрактальную размерность границ водосборных бассейнов на основе связи между площадью и периметром бассейнов.

Используется логарифмическая зависимость:

```text
log S = (2 / D) * log P + c
````

где:

* `S` — площадь бассейна;
* `P` — периметр бассейна;
* `D` — фрактальная размерность границы бассейна.

Для расчёта можно использовать старший бассейн и несколько уровней вложенных бассейнов.

### 3. Расчёт `D_Hav` и `D_Hsum`

Модуль рассчитывает характеристики самоподобия речной сети на основе длин водотоков разных порядков.

Поддерживаются два варианта расчёта:

* по средней длине водотоков заданного порядка;
* по суммарной длине водотоков заданного порядка.

Модуль позволяет анализировать, как структура речной сети изменяется в зависимости от порядка водотоков.

### 4. Расчёт параметра `λ`

Модуль рассчитывает параметр самоподобия распределения водотоков по длинам.

Используется зависимость:

```text
log N = -λ * log L + c
```

где:

* `N` — количество водотоков в диапазоне длин;
* `L` — длина водотока или центр интервала длин;
* `λ` — параметр самоподобия распределения длин.

Программа строит интервалы длин, выполняет логарифмическое преобразование и подбирает участок для линейной аппроксимации.

### 5. Расчёт корреляционной размерности `D_cor`

Модуль рассчитывает корреляционную размерность множества точек бифуркации речной сети.

Используется зависимость:

```text
C(r) ~ r^Dcor
```

где:

* `C(r)` — корреляционная сумма;
* `r` — масштаб расстояний;
* `D_cor` — корреляционная размерность.

Расчёт основан на попарных расстояниях между точками бифуркации и линейной аппроксимации зависимости в логарифмическом масштабе.

## Стек технологий

Проект написан на Python и использует следующие библиотеки:

* PyQt5 — графический интерфейс;
* pandas — работа с табличными данными;
* NumPy — численные вычисления;
* SciPy — линейная регрессия и статистические расчёты;
* Matplotlib — построение графиков и распределений.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/sanycool/River_fractal_analysis.git
cd River_fractal_analysis
```

### 2. Создать виртуальное окружение

Для Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Для Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## Запуск приложения

```bash
python main.py
```

После запуска откроется главное окно приложения **River Fractal Analysis**.

## Формат входных данных

Приложение работает с CSV-файлами.

Основные требования:

* разделитель столбцов — `;`;
* числовые значения могут использовать точку или запятую в качестве десятичного разделителя;
* названия колонок выбираются пользователем в интерфейсе;
* файл должен содержать данные, необходимые для выбранного расчётного модуля.

Пример запуска работы:

1. Открыть приложение.
2. Перейти в меню **Файл → Открыть файл**.
3. Выбрать CSV-файл.
4. Перейти в меню **Расчёт**.
5. Выбрать нужный модуль.
6. Настроить соответствие колонок.
7. Запустить расчёт.
8. Сохранить результат в CSV.

## Основные типы данных

В зависимости от выбранного модуля могут потребоваться следующие данные:

### Для бассейнов

* ID бассейна;
* широта центроида;
* долгота центроида;
* площадь бассейна;
* периметр бассейна.

### Для водотоков

* порядок водотока / `gridcode`;
* ID сегмента или объединённого водотока;
* длина сегмента или объединённого водотока;
* начальный узел сегмента;
* конечный узел сегмента.

### Для точек бифуркации

* ID точки бифуркации;
* широта точки;
* долгота точки;
* порядок точки / `gridcode`.

## Работа с фильтрацией

В расчётных модулях можно задавать ограничения для отбора данных:

* по площади бассейна;
* по периметру бассейна;
* по длинам водотоков;
* по порядкам водотоков;
* по количеству точек или интервалов аппроксимации.

Для некоторых параметров доступна визуализация распределений, которая помогает подобрать корректные границы фильтрации.

## Выходные данные

После расчёта приложение формирует таблицу с результатами.

В зависимости от модуля выходной файл может содержать:

* ID бассейна;
* координаты бассейна;
* площадь и периметр;
* рассчитанное значение фрактального параметра;
* коэффициент детерминации `R²`;
* стандартную ошибку аппроксимации;
* количество использованных водотоков, бассейнов или точек;
* интервал аппроксимации.

Результат можно сохранить через кнопку **Сохранить** в окне расчёта или через меню **Файл → Сохранить как**.

## Встроенная справка

Если CSV-файл не загружен, в главном окне отображается справка по основным модулям приложения.

Справка содержит:

* описание назначения каждого модуля;
* краткую методику расчёта;
* пояснение к полям интерфейса;
* описание фильтрации;
* описание кнопок управления расчётом.
