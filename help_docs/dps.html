Расчет фрактальной размерности границ бассейнов (D)

Методика расчета

Фрактальная размерность D оценивает степень изрезанности границ речных бассейнов на основе соотношения между их площадями (S) и периметрами (P). Метод основан на логарифмической зависимости:

log S = (2/D) × log P + c

Для получения значения D строится зависимость площади от периметра в двойном логарифмическом масштабе, затем выполняется линейная аппроксимация. Угловой коэффициент прямой позволяет определить значение D.

Назначение окна

Интерфейс модуля позволяет пользователю задать данные для расчета параметра D для выбранных старших бассейнов и вложенных в него бассейнов.

Также предоставлены гибкие настройки фильтрации бассейнов по площади и периметру.

Пользователю необходимо настроить:

В блоке "Колонки старшего бассейна"

ID старшего бассейна Колонка уникального идентификатора старших бассейнов
Широта (latitude, Y) центроида бассейна Колонка с широтами центроидов бассейнов
Долгота (longitude, X) центроида бассейна Колонка с долготами центроидов бассейнов
Периметр старшего бассейна Колонка с периметрами старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)
Площадь старшего бассейна Колонка с площадьми старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)

В блоке "Колонки вложенных бассейнов"

Важно: можно добавить или удалить уровни вложенных бассейнов кнопками «Добавить» / «Удалить».

Для каждого уровня вложенности указываются колонки:
ID Колонка уникального идентификатора старших бассейнов
Периметр Колонка с периметрами старших бассейнов, ниже в графе диапазон: можно задать min и max значения (опционально)
Площадь Колонка с площадьми старших бассейнов, ниже в графе диапазон: можно задать min и max значения (опционально)

Фильтрация и визуализация распределения

По нажатию на иконку с диаграммой возле полей выбора можно построить распределение выбранного параметра (периметра или площади) для бассейнов указанного порядка.

Построенная гистограмма отображается в левом блоке окна. Ниже пользователь может задавать:

  • Количество интервалов (bins) гистограммы.
  • Диапазон фильтрации по средней площади (в процентах).
  • Диапазон фильтрации по квантилям (в процентах).
  • Диапазон фильтрации по явным числовым значениям (min / max).

Ниже диаграммы распределения отобразятся рассчитанные границы, которые можно будет использовать в расчетах.

Управление расчетом

Расчет Запускает вычисление параметра D с учётом всех заданных настроек и фильтраций
Сохранить Сохраняет результат в CSV-файл после завершения расчета
Готово Закрывает окно после завершения расчета
Отмена Отменяет расчёт и закрывает окно

Прогресс выполнения и сообщения отображаются в области логов.
