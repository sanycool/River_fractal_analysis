Расчет параметра самоподобия распределения водотоков по длинам (λ)

Методика расчета

Параметр самоподобия λ характеризует степень изменения количества водотоков выбранных порядков в зависимости от их длины. Используется логарифмическая зависимость вида:

log N = –λ × log L + c

где N — количество водотоков данного диапазона длин L, L — значение длины данного диапазона, а λ — искомый параметр.

Для расчёта λ производится автоматизированный перебор всех возможных диапазонов длин, начиная от заданного порога. Для каждого участка вычисляется λ, R² и стандартная ошибка. В качестве финального значения выбирается λ, соответствующий интервалу с минимальным значением наклона.

Назначение окна

Данный модуль позволяет вычислить λ для каждого бассейна старшего порядка на основе распределения длин водотоков выбранных порядков, входящих в него.

Также предоставлены гибкие настройки фильтрации данных по площади, периметру или длинам водотоков.

Пользователю необходимо настроить:

Колонки параметров бассейнов

ID старшего бассейна Колонка уникального идентификатора старших бассейнов
Широта (latitude, Y) центроида бассейна Колонка с широтами центроидов бассейнов
Долгота (longitude, X) центроида бассейна Колонка с долготами центроидов бассейнов
Периметр старшего бассейна Колонка с периметрами старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)
Площадь старшего бассейна Колонка с площадьми старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)

Колонки параметров русел

Порядки отрезков рек (grid code) Колонка с порядками водотоков (Выбирать аккуратно!)
ID объединенных рек Колонка с идентификаторами объединённых водотоков
Длины объединенных рек Колонка с длинами объединённых водотоков

Ниже располагается область, в которой отобразятся существующие порядки водотоков (после выбора "Порядки отрезков рек (grid code)"). В данной области необходимо выбрать, какие порядки водотоков будут участвовать в расчетах, а также диапазоны длин для отсечения.

Ниже области выбора порядков водоток будет отображаться обновляемая статистика для выбранных порядков водотоков, включающая количество водотоков, минимальную и максимальную длину среди водотоков. Это поможет для Настройки гистограммы.

Напротив надписи "Выберите порядки рек для расчетов" расположена кнопка "Показать графики распределения длин русел для бассейнов". При нажатии на эту кнопку в левой области окна отобразятся графики распределения длин для водотоков выбранных порядков (поэтому при построении графиков распределения для вычисления диапазонов длин рекомендуется выбирать каждый порядок отдельно).

Настройки гистограммы

Шаг интервала гистограммы Контролирует размер диапазонов длин (L в формуле выше) для построения гистограммы
Порог длины русла (Опционально) Указывается минимальная и максимальная длины водотоков, не зависимо от их порядка
Минимальный интервал аппроксимации Минимальное количество "точек" на гистограмме", которое будет аппроксимировано для нахождения λ (минимальное значение: 3)

Фильтрация и визуализация распределения

По нажатию на иконку с диаграммой возле полей выбора можно построить распределение выбранного параметра (периметра или площади) для старших бассейнов. При нажатии кнопки "Показать графики распределения длин русел для бассейнов" строится график распределения длин русел выбранных порядков.

Построенная гистограмма отображается в левом блоке окна. Ниже пользователь может задавать:

  • Количество интервалов (bins) гистограммы.
  • Диапазон фильтрации по средней площади (в процентах).
  • Диапазон фильтрации по квантилям (в процентах).
  • Диапазон фильтрации по явным числовым значениям (min / max).

Ниже диаграммы распределения отобразятся рассчитанные границы, которые можно будет использовать в расчетах.

Управление расчетом

Расчет Запускает вычисление параметра λ с учётом всех заданных настроек и фильтраций
Сохранить Сохраняет результат в CSV-файл после завершения расчета
Готово Закрывает окно после завершения расчета
Отмена Отменяет расчёт и закрывает окно

Прогресс выполнения и сообщения отображаются в области логов.
