Добро пожаловать в River Fractal Analysis!

Это приложение предназначено для фрактального анализа речных сетей. Вы можете:

Соединить отрезки водотоков Провести индексацию фрагментированных водотоков разных порядков, получая объединенные сегменты и (опционально) их длины
Рассчитать D Вычислить фрактальную размерность границ бассейнов водосбора старших порядков по соотношению площади и периметра вложенных в них бассейнов меньшего порядка
Рассчитать DHav Вычислить характеристику самоподобия зависимости длин водотоков от их порядка для бассейнов старших порядков
Рассчитать λ Вычислить характеристику самоподобия распределения длин водотоков выбранных порядков для бассейнов старших порядков
Рассчитать Dcor Вычислить корреляционную размерность множества точек бифуркации для бассейнов старших порядков

Как начать работу:

  1. Перейдите в меню Файл → Открыть и выберите CSV-файл (разделитель должен быть ";")
  2. Выберите нужный модуль в меню Расчёт
  3. Следуйте инструкциям в открывшемся диалоговом окне
