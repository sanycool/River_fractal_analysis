Соединение сегментов рек и расчёт длины объединённых водотоков

Назначение модуля

Данный инструмент предназначен для объединения фрагментов водотоков в связные компоненты (реки) и расчёта их общей длины. Это необходимо для формирования топологически целостных рек и дальнейших гидрологических и фрактальных расчётов.

Принцип работы

1. Объединение отрезков (индексация рек)

Каждой связной группе отрезков, соединённых через узлы начала и конца, присваивается уникальный идентификатор реки (RIVER_ID).

Алгоритм выполняется по следующей схеме:

  • Отдельно для каждого порядка водотока (grid_code)
  • Создаётся граф связей по колонкам "откуда" и "куда"
  • Определяются компоненты связности
  • Назначается уникальный индентификатор каждой компоненте

Результат сохраняется в новую колонку RIVER_ID.

Если установлен флаг «Пересчитать длины для соединенных сегментов», производится расчёт суммарной длины каждой объединённой реки, результат которой сохранится в новую колонку R_LENGTH.

Пользователю необходимо настроить:

Колонка порядков сегментов водотоков Поле, в котором указаны порядки каждого сегмента (например, grid_code)
Колонка идентификатора начала узла Уникальный идентификатор начальной точки сегмента (например, from_node)
Колонка идентификатора конца узла Уникальный идентификатор конечной точки сегмента (например, to_node)
Колонка длины сегментов Опционально

Управление расчетом

Расчет Запускает обработку и расчёты по заданным колонкам
Готово Закрывает окно после завершения расчета
Отмена Отменяет расчёт и закрывает окно

Прогресс выполнения и сообщения отображаются в области логов.
