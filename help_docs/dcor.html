Расчёт корреляционной размерности множества точек бифуркации (Dcor)

Методика расчёта

Параметр Dcor описывает, как плотность множества точек бифуркации зависит от масштаба. Используется зависимость:

C(r) ∼ rDcor

где C(r) — корреляционная сумма, зависящая от масштаба r, Dcor — искомый коэффициент самоподобия.

Для вычисления C(r) берутся все попарные расстояния rij между точками бифуркации. Затем считается корреляционная сумма для разных масштабов r:

C(r) = (1/N²) ∑i,j Θ(r − rij)

где N — общее число точек бифуркации, а Θ — функция Хевисайда (равна 1, если r − rij > 0, иначе 0).

Полученная зависимость C(r) строится в двойном логарифмическом масштабе, а затем аппроксимируется та часть графика, которая максимально приближена к крутопадающей прямой линии. Эта прямая имеет вид:

log C(r) = Dcor · log r + c

Назначение окна

Модуль позволяет рассчитать параметр Dcor для каждого бассейна выбранного старшего порядка на основе точек бифуркации выбранных порядков, входящих в него.

Также предоставлены гибкие настройки фильтрации бассейнов по площади и периметру.

Пользователю необходимо настроить:

(Левая область) Колонки параметров бассейнов

ID старшего бассейна Колонка уникального идентификатора старших бассейнов
Широта (latitude, Y) центроида бассейна Колонка с широтами центроидов бассейнов
Долгота (longitude, X) центроида бассейна Колонка с долготами центроидов бассейнов
Периметр старшего бассейна Колонка с периметрами старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)
Площадь старшего бассейна Колонка с площадьми старших бассейнов, ниже в графе диапазон: можно задать диапазон значений (опционально)

(Левая область) Настройки вычислений

Шаг масштаба r [м] Определяет интервал, с которым будут считаться значения C(r) (в метрах)
Минимальный интервал аппроксимации Минимальное количество "точек" на гистограмме", которое будет аппроксимировано для нахождения Dcor (минимальное значение: 3)
(Флаг)Использовать весь интервал При выборе отключает ограничение на минимальный диапазон отрезка и берёт весь интервал
Радиус Земли исследуемой области [км] Влияет на перевод координат в расстояния (в километрах) (по умолчанию 6371)
